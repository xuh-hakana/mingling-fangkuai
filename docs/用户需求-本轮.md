【2026-11-07 鼠标居中发白 + 随机变化 需求原文（她原话，未改一字）】

「我鼠标放到中间会把雨珠变白色。然后你再多一个雨珠大小、雨量、窗口模糊随机动态变化的选项」

【本轮落地（2026-11-07）】
- 修「鼠标居中雨珠变白」：根因是**雨珠高光方向完全绑给了指针** —— 指针居中时 `raindropLightPos` 变成 `[0,0,2,0]`，光正对镜头，每颗水珠的镜面高光全顶到最亮、糊成一团白。
  改法：以库原本的左上光 `[-1,1,2,0]` 为基准，指针只做 ±0.45 的小偏移 → `[-1 + curX*0.45, 1 - curY*0.45, 2, 0]`；居中时回到原版光位，不再发白。同时把镜面光强度 `[0.92,0.94,1.06]` 降到 `[0.80,0.82,0.94]`，留出余量。
  实测（指针正中 vs 左上角，同区域像素统计）：近白像素 79 vs 70（欢迎区）、511 vs 511（代码区），无白斑尖峰。
- 新增「随机变化」开关（面板第 7 行，整条按钮，开启时青紫渐变填充 + 右侧状态「开」）：
  - 控制 3 项：雨珠大小（`spawnSize`）、雨量（`dropletsPerSeconds`）、窗口模糊（`--rain-blur`）。
  - 起伏范围以你拖的基准为中心：大小 ±34%（夹 20~140px）、雨量 ±45%（夹 40~600）、模糊 ±max(2, 基准×60%)（夹 0~20px）。
  - 节奏：每 1.8~3.8 秒换一个新目标，按**真实时间步长**缓动（时间常数 0.9s，`1 - exp(-dt/0.9)`），约 2 秒走到目标九成 → 持续缓慢起伏，不跳变；不按帧数算，掉帧或后台节流时也不会变慢。
  - 随机只改「当下生效值」，不动你拖的基准：关掉开关精确回到基准（实测关掉后 `--rain-blur` 精确回 `8px`）；「恢复默认」会一并关掉随机。
  - 随机开着时拖这三项：随机当前值/目标值同步成你拖到的新值，并推迟 3 秒再起伏（实测拖到 3px → 600ms 后仍 3.00px，4 秒后开始 3.52px 起伏）。
  - 开关状态存 localStorage（`rand:1/0`），重开客户端继续。
- 面板高度 413 → 481px，仍在视口内（`place()` 按实测高度决定向下或向上翻）。
- 真机验收（CDP + SwiftShader，前台+焦点，0 控制台报错）：随机连采 4 次 `--rain-blur` = 7.48 / 3.92 / 11.04 / 11.51px（4 个不同值）；关掉回 8px；默认值恢复且 rand 归 0；刷新后状态「开」且继续起伏；滑杆标签始终显示基准值（不被随机值污染）。

【2026-11-07 追加：随机也驱动高光 需求原文（她原话，未改一字）】

「随机也能变高光位置」

【落地（2026-11-07）】
- 随机项从 3 项扩到 4 项：雨珠大小 / 雨量 / 窗口模糊 / **高光位置**。面板按钮文案同步为「雨珠大小 / 雨量 / 模糊 / 高光 自动起伏」。
- 做法：新增 `applyLight()` 统管光源写入 = 库原始左上光 `[-1,1,2,0]` + 指针偏移 `±0.45` + 随机漂移 `lx/ly`。
  - 之前光照只在 `parallaxTick()` 里写，指针一停就不再写 → 只改那处的话，随机永远动不了高光。现在 `randFrame()` 每帧也调 `applyLight()`。
  - 漂移范围：`lx ∈ [-0.5, 0.5]`、`ly ∈ [0, 0.55]`；**纵向不给负值**，永远保留向上的分量，避免光源靠近镜头正前方 `[0,0,z]` 把雨珠炸白。
  - 与 blur/drop/flow 同一套时间步长缓动（`1-exp(-dt/0.9)`），一起 1.8~3.8 秒换目标。
  - 关掉随机时 `lx/ly` 归零并立即 `applyLight()`，高光精确回到「左上基准 + 指针」。
- 实测（CDP + SwiftShader，带 `?raindbg=1` 只读快照）：随机关时 light 稳定 `[-1, 0.96, 2]`；随机开、指针不动，5 次采样 x/y 全部不同（x −0.715 → −0.952，y 1.188 → 1.098），**xy 模长最小 1.33**（远离 0 = 不会发白），z 恒为 2；随机开时指针移到左上，light `[-1.293, 1.355]`（漂移 + 指针偏移叠加生效）；关随机后回到 `[-1+指针偏移, 1−指针偏移]`，0 控制台报错。
- 为可验证性新增只读调试口：URL 带 `?raindbg=1` 时暴露 `window.__rainDebug()`（返回 rand/light/drop/flow/blur/curX/curY），正常使用没有这个全局。
